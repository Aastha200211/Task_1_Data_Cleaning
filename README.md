# Task1-Data-Cleaning-and-Preprocessing
## Objective

The objective of this task was to clean and preprocess a raw dataset by identifying missing values, duplicate records, inconsistent formats, and data-quality issues.

## Dataset

Mall Customer Segmentation Data

## Tool Used

Python
Pandas
NumPy
Matplotlib

## Data Cleaning Steps

- Loaded and inspected the dataset
- Checked missing values
- Checked duplicate records
- Standardized text values
- Renamed column headers
- Checked data types
- Checked invalid values
- Performed outlier detection
- Validated the cleaned dataset
- Exported the cleaned dataset

## Files

- `mall_customers.csv` - Original dataset
- `cleaned_mall_customers.csv` - Cleaned dataset
- `Task_1_Data_Cleaning.ipynb` - Python notebook
- `data_cleaning_summary.txt` - Summary of changes

## Conclusion

The dataset was cleaned and prepared for further analysis and visualization.
